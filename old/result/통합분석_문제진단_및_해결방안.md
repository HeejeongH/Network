## 🔍 문제 진단

### 1. 핵심 문제: 잘못된 데이터 열 선택

```python
# 현재 코드 (문제 있음)
food_groups_agg = data.iloc[:, 15:27]  # ❌ 이 열들은 식품군이 아님!
```

**실제로 선택된 열:**
- `Antidiabetic Medication` (당뇨약 복용 여부)
- `Hyperlipidemia` (고지혈증 여부)
- `Statin Medication` (스타틴 복용 여부)
- `Angina/Myocardial Infarction` (협심증/심근경색 여부)
- `Stroke` (뇌졸중 여부)
- `Chronic kidney disease` (만성 신장질환 여부)
- `SBP`, `DBP` (혈압)
- `Total Cholesterol`, `Triglycerides`, `LDL-C`, `HDL-C` (지질 지표)

**문제점:**
1. 이들은 **건강지표/질병변수**이지 **식품군 섭취 점수가 아님**
2. 대부분 이진변수(0/1)로 구성되어 있음
3. Co-occurrence 네트워크 구축에 부적절한 데이터 타입

### 2. 결과적 문제

#### Poor Diet 네트워크 (score=1):
- 유효 co-occurrence 값: 15개만 존재
- 대부분의 사람들이 질병이 없어(0) score=1인 경우가 적음
- 중앙값(median) 임계값 사용 시 일부 엣지만 생성

#### Non-Poor Diet 네트워크 (score≥3):
- **모든 정규화된 co-occurrence 값이 1.0000**
- 이는 건강지표 변수의 특성상 score≥3 조건이 의미없음
- 결과: **0개의 엣지** 생성

### 2단계: Co-occurrence 함수 개선

```python
def build_cooccurrence_network_improved(data, food_cols, threshold_low=1, 
                                       threshold_high=None, threshold_percentile=70):
    """
    개선된 co-occurrence 네트워크 구축 함수
    
    Parameters:
    - threshold_low: 소비 기준 하한 (예: 1 = poor diet)
    - threshold_high: 소비 기준 상한 (None = 하한 이상 모두 포함)
    - threshold_percentile: 엣지 생성 임계값 백분위수 (70 권장)
    """
    # 이진화
    if threshold_high is None:
        consumed = (data[food_cols] >= threshold_low).astype(int)
    else:
        consumed = (data[food_cols] == threshold_low).astype(int)
    
    # Co-occurrence 행렬 계산
    cooccur_matrix = consumed.T.dot(consumed).values
    
    # 정규화
    occurrence = consumed.sum(axis=0).values
    with np.errstate(divide='ignore', invalid='ignore'):
        cooccur_normalized = cooccur_matrix / np.sqrt(np.outer(occurrence, occurrence))
        cooccur_normalized = np.nan_to_num(cooccur_normalized, 0)
    
    # 네트워크 생성
    G = nx.Graph()
    for food in food_cols:
        G.add_node(food)
    
    # Percentile 기반 임계값
    values = cooccur_normalized[np.triu_indices_from(cooccur_normalized, k=1)]
    values = values[values > 0]
    
    if len(values) > 0:
        threshold = np.percentile(values, threshold_percentile)
    else:
        return G, pd.DataFrame(cooccur_normalized, index=food_cols, columns=food_cols)
    
    # 엣지 추가
    for i in range(len(food_cols)):
        for j in range(i+1, len(food_cols)):
            if cooccur_normalized[i, j] > threshold:
                G.add_edge(food_cols[i], food_cols[j], weight=cooccur_normalized[i, j])
    
    return G, pd.DataFrame(cooccur_normalized, index=food_cols, columns=food_cols)
```
