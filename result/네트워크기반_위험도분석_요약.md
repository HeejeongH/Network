## 🎯 프로젝트 목표의 진화

### 문제 인식

**기존 방식의 한계:**
```
"당신은 남성 중년층이므로
→ 이런 식습관을 가지고 있을 것입니다
→ 이렇게 바꾸세요"
```

**문제점:**
- ❌ 개인의 실제 위험 요인을 고려하지 않음
- ❌ "왜 이것이 위험한가"에 대한 과학적 설명 부족
- ❌ 우선순위가 모호함 (모든 것을 개선하라는 일반적 조언)

### 새로운 접근

**Risk-based 방식:**
```
"당신의 연령/성별에서
→ 이 식품이 MetS에 가장 큰 영향을 미칩니다
→ 우선적으로 주의하세요"
```

**장점:**
- ✅ 과학적 근거 기반 위험도 평가
- ✅ 직접 효과 + 간접 효과 + 네트워크 효과 통합
- ✅ 명확한 우선순위 제공
- ✅ "왜 위험한가" 설명 가능

## 🔬 방법론 상세

### 통합 위험도 점수 (Integrated Risk Score)

```python
Risk_Score = (Direct_Effect × 0.4) + (Network_Centrality × 0.3) + (Indirect_Effect × 0.3)
```

#### 1. 직접 효과 (Direct Effect) - 40%

**측정 방법:**
- 식품과 MetS 5개 성분 간 Spearman 상관계수
  - Waist circumference (허리둘레)
  - Systolic blood pressure (수축기 혈압)
  - Diastolic blood pressure (이완기 혈압)
  - Triglycerides (중성지방)
  - Fasting glucose (공복 혈당)

**해석:**
- 높을수록 → 이 식품이 MetS 성분과 직접적으로 강하게 연관
- 예: Fried Foods와 TG, WC 간 높은 상관

#### 2. 네트워크 중심성 (Network Centrality) - 30%

**측정 방법:**
- GGM (Gaussian Graphical Model) 네트워크에서 Degree Centrality
- 이 식품이 다른 식품들과 얼마나 많이 연결되어 있는가

**해석:**
- 높을수록 → 식습관 패턴의 핵심 허브
- 이 식품을 바꾸면 → 다른 여러 식품도 함께 변화 가능
- 예: Protein Foods가 중심성이 높다면, 이를 개선하면 전체 식단 품질 향상

#### 3. 간접 효과 (Indirect Effect) - 30%

**측정 방법:**
```python
Indirect_Effect = Σ (Edge_Weight × Neighbor_Direct_Effect)
```

**해석:**
- 이 식품이 연결된 다른 식품들을 통해 MetS에 미치는 간접 영향
- 예: SSB가 Fried Foods와 강하게 연결 → SSB의 간접 효과 증가

## 📊 주요 결과

### 1. 식품별 평균 위험도 (전체)

**상위 5개 고위험 식품:**
1. Protein Foods (0.548)
2. Processed Foods (0.543)
3. Vegetables (0.538)
4. Salty Food Consumption (0.517)
5. Additional Salt Use (0.475)

### 2. MetS(+) vs MetS(-) 비교

**MetS(+)에서 특히 위험도가 높은 식품:**
- Fried Foods: +0.027 (MetS+ > MetS-)
- Sweet Food Consumption: +0.032
- Sugar-Sweetened Beverages: +0.008

**MetS(-)에서 오히려 높은 식품 (역설적):**
- Protein Foods: -0.080 (MetS+ < MetS-)
- Vegetables: -0.082
- Salty Food Consumption: -0.074

**해석:**
- 건강 식품(채소, 단백질)은 MetS(-) 그룹에서 더 중심적 역할
- MetS(+) 그룹은 불건강 식품의 위험도가 상대적으로 높음
- 그룹별 맞춤형 접근의 필요성 확인

### 3. 그룹 간 위험도 차이

**가장 큰 차이를 보이는 식품:**
1. Grain Products: 2.1배 차이 (최고 vs 최저)
2. Sweet Food Consumption: 1.9배
3. Sugar-Sweetened Beverages: 1.8배

**의미:**
- 동일 식품이라도 개인 특성(성별, 연령, MetS)에 따라 위험도가 크게 다름
- 획일적 교육보다 개인 맞춤형 우선순위 필요

## 💡 교육 메시지 예시

### 기존 방식 (Descriptive)

```
그룹: 남성, 중년층, MetS(+)

[우선순위 1: Sugar-Sweetened Beverages]
- 이유: 네트워크 허브 식품입니다 (중심성 0.89)
- 조치: 당류 음료 섭취를 줄이세요
```

**문제:**
- 왜 위험한지 명확하지 않음
- 중심성만으로는 MetS 위험도를 설명하기 어려움

### 새로운 방식 (Risk-based)

```
그룹: 남성, 중년층, MetS(+)

[우선순위 1: Processed Foods]
위험도 점수: 0.587

왜 위험한가?
  ① 직접 효과: MetS 성분과 중등도 상관 (r=0.035)
  ② 네트워크 중심성: 전체 식습관 패턴의 핵심 허브 (중심성=1.00)
  ③ 간접 효과: 다른 불건강 식품과 강하게 연결되어 복합적 영향 (경로 강도=1.00)

무엇을 해야 하나?
  • 가공식품(햄, 소시지 등) 섭취를 줄이세요
  • 대체 식품: 신선한 고기, 생선, 계란
  • 실천 방법: 가공되지 않은 신선식품 선택

연령·성별 맞춤:
  • 만성질환 예방을 위해 지금부터 식습관 개선이 중요
  • 음주 시 안주 선택에 주의
```

**개선점:**
- ✅ 3가지 차원(직접/간접/네트워크)에서 위험 이유 설명
- ✅ 수치로 명확한 우선순위 제공
- ✅ 실행 가능한 구체적 조언

## 🎯 임상 적용 가이드

### 위험도 기반 우선순위 설정

**초고위험 (Risk Score ≥ 0.6):**
- 즉각적 개입 필요
- 월 1회 모니터링
- 영양사 상담 권장

**고위험 (0.5 ≤ Risk Score < 0.6):**
- 3개월 내 개입
- 분기별 모니터링
- 교육 자료 제공

**중위험 (0.4 ≤ Risk Score < 0.5):**
- 6개월 내 개입
- 반기별 모니터링
- 예방적 교육

**저위험 (Risk Score < 0.4):**
- 현재 상태 유지
- 연 1회 점검

### 시스템 통합 예시

```python
def get_risk_based_education(sex, age, mets_status):
    """
    개인 정보를 입력받아 맞춤형 교육 콘텐츠 반환
    """
    # 1. 그룹 매칭
    age_group = categorize_age(age)
    group_key = f"{sex}_{age_group}_{mets_status}"
    
    # 2. 해당 그룹의 위험도 데이터 조회
    risk_data = load_risk_scores(group_key)
    
    # 3. 위험도 순위 정렬
    sorted_risks = risk_data.sort_values('Risk_Score', ascending=False)
    
    # 4. 상위 3개 식품 선택
    top_risks = sorted_risks.head(3)
    
    # 5. 교육 메시지 생성
    education_messages = []
    for _, risk in top_risks.iterrows():
        message = {
            'food': risk['Food'],
            'risk_score': risk['Risk_Score'],
            'risk_reason': explain_risk(
                direct=risk['Direct_Effect'],
                centrality=risk['Network_Centrality'],
                indirect=risk['Indirect_Effect']
            ),
            'action_plan': get_action_plan(risk['Food']),
            'alternatives': get_alternatives(risk['Food']),
            'age_specific': get_age_message(age_group),
            'sex_specific': get_sex_message(sex)
        }
        education_messages.append(message)
    
    return education_messages
```
