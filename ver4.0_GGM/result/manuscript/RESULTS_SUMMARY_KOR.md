## 3.5. 통합 식이 전략 (Integrated Dietary Strategy)

### 개인맞춤형 허브 식품 기반 전략

#### 예방 전략 (Prevention Strategy for MetS-)

**REDUCE (감소해야 할 위험 허브)**:
- **남성 청년/중년**: 튀김식품, 가공식품
- **여성 청년**: 튀김식품, 당류 음료
- **여성 중년**: 튀김식품
- **여성 장년**: 당류 음료, 고지방 육류

**PROMOTE (증가해야 할 보호 허브)**:
- **남성 청년**: 채소
- **남성 중년**: 채소
- **남성 장년**: 단백질식품

**기대효과**:
- 위험 허브 감소 → BMI -0.3~-0.8 kg/m², 허리둘레 -0.7~-2.4 cm, 중성지방 -8~-11 mg/dL
- 보호 허브 증가 → 중성지방 -9 mg/dL, HDL-C +1~2 mg/dL
- 위험요인 개수 약 0.1개 감소

#### 관리 전략 (Management Strategy for MetS+)

**REDUCE (감소해야 할 악화 허브)**:
- **남성 청년**: 곡물제품
- **남성 중년**: 튀김식품, 가공식품, 단백질식품 (과잉섭취 주의)
- **남성 장년**: 가공식품
- **여성 중년**: 튀김식품, 가공식품
- **여성 장년**: 특별한 악화 허브 없음

**PROMOTE (증가해야 할 완화 허브)**:
- **여성 장년**: 단백질식품 (적정량)

**기대효과**:
- 악화 허브 감소 → BMI -1.0~-1.6 kg/m², 허리둘레 -2.5~-3.3 cm
- 악화 허브 감소 → 수축기혈압 -4~-6 mmHg, 중성지방 -13~-43 mg/dL
- 완화 허브 증가 → 공복혈당 -14.7 mg/dL

#### 네트워크 계단식 효과 (Network Cascade Mechanism)

**허브 1개 조절 → 연결된 5-7개 식품 자동 조절**:
- 튀김식품 감소 → 가공식품, 고지방 육류, 당류 음료도 감소
- 채소 증가 → 과일, 단백질식품도 증가
- 적은 노력으로 큰 효과 (레버리지 효과)

## 효과크기 해석 (Effect Size Interpretation)

### Cohen's d 기준
- **Negligible (무시 가능)**: d < 0.2
- **Small (작음)**: 0.2 ≤ d < 0.5
- **Medium (중간)**: 0.5 ≤ d < 0.8
- **Large (큼)**: d ≥ 0.8

### 본 연구의 효과크기
- **대부분 Small to Medium** (d = 0.2-0.5)
- 통계적 유의성(p<0.05) + 임상적 의미 모두 확인
- 예시:
  - BMI 0.5-1.5 kg/m² 차이 → d ≈ 0.2-0.4
  - 허리둘레 1-3 cm 차이 → d ≈ 0.2-0.4
  - 중성지방 10-40 mg/dL 차이 → d ≈ 0.2-0.5

### 임상적 의미
- Cohen's d 0.2-0.5 = 대사증후군 위험도 10-20% 변화
- 작은 효과크기라도 인구집단 수준에서 큰 영향
- 장기적 누적효과 고려 시 더 큰 의미

## 핵심 메시지

### 연구의 혁신성
1. **네트워크 과학 × 영양학**: 허브 식품 개념 최초 도입
2. **개인맞춤형 접근**: 성별·연령·MetS 여부별 11개 전략
3. **예방 vs 관리 구분**: 건강인과 환자에게 다른 전략
4. **효율적 중재**: 전체 식단 대신 3-5개 허브 식품만 조절

### 실용적 가치
- **영양사**: 상담 시 허브 식품 우선 강조
- **디지털 헬스**: 개인맞춤 허브 추천 앱 개발 가능
- **공공보건**: 인구집단별 타겟 허브 캠페인

### Take-home Message
> **"모든 것을 바꿀 필요 없다. 올바른 식품(허브)을 바꾸면, 나머지는 따라온다."**
